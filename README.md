# Flutter Code Study

Flutter와 Dart 기반의 수업 실습 프로젝트를 모아 둔 저장소입니다.

## 구성
- `mvvm/`: MVVM 패턴 및 GetX 관련 예제 앱
- 하위 폴더별로 독립적인 Flutter 프로젝트가 포함되어 있습니다.

## 실행 방법
1. Flutter SDK를 설치합니다.
2. 실행하려는 앱의 프로젝트 폴더로 이동합니다.
3. `flutter pub get`으로 의존성을 설치합니다.
4. `flutter run`으로 실행합니다.

```bash
cd mvvm/getx
# 실행할 앱 폴더로 이동한 뒤
flutter pub get
flutter run
```

> 앱별 의존성과 실행 방법은 각 하위 프로젝트의 README 및 설정 파일을 확인해 주세요.
